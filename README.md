# Tasky

Tasky is a kanban board with subtasks, countdown timers, stopwatches, and optional Google account sync.

**Open Tasky:** https://brentcrosby.github.io/time-slice-kanban-board/

The app is published automatically to GitHub Pages when `main` is pushed. Firebase Authentication and Cloud Firestore still provide sign-in and cross-device task sync; hosting the app on GitHub Pages does not require a Firebase CLI login for routine updates.

For local development and Firebase setup, see [FIREBASE_SETUP.md](./FIREBASE_SETUP.md).
